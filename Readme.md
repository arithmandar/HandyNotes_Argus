## About

**[HandyNotes - Argus](https://www.curseforge.com/wow/addons/handynotes-argus)** is a plugin for [HandyNotes](https://www.curseforge.com/wow/addons/handynotes).

It adds markers to the Argus world map for notable points of interest, including rare creature locations and other useful map nodes.

HandyNotes is required. This addon does not function as a standalone addon.

## Features

- Displays points of interest across Argus.
- Shows rare creature locations.
- Lets you choose which categories of nodes to display.
- Lets you adjust icon size and transparency.
- Lets you hide individual nodes from the world map.

## Configuration and Hiding Nodes

Open the AddOns settings and select **HandyNotes - Argus** to configure which node categories are displayed and adjust the icon scale and transparency.

To hide a specific node, right-click its icon on the world map and choose the hide option. Hidden nodes can be restored from the addon settings.

## Missing or Incorrect Nodes

If you find a missing, incorrect, or outdated node, please submit an issue through the [issue tracker](https://www.curseforge.com/wow/addons/handynotes-argus/issues).

When reporting a location, please include:

- The node name or a brief description.
- Its map coordinates.
- Any relevant conditions, such as quest progress, faction, or world state.
- A screenshot, if useful.

Please provide coordinates to two decimal places when possible, for example: `39.66, 31.89`.

If you need an addon that displays your current coordinates, you can use [Coordinates Tracking](https://www.curseforge.com/wow/addons/coordinates-tracking).
